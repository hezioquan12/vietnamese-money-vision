# Developer Excellence & Ponytail Master Skills Pack for Antigravity

Trọn bộ **51 Skills Kỹ sư Chuyên nghiệp** dành cho Antigravity AI Assistant, bao gồm bộ công cụ Ponytail (Senior Dev Mode), Epistemic Rigor (xác minh ground-truth), Kiến trúc sâu (Deep Codebase Design), TDD, Chuẩn hóa UI/UX WCAG AAA, và Quy trình Spec-Driven.

## 🚀 Hướng Dẫn Cài Đặt Cho Dự Án Khác

### Cách 1: Cài đặt Toàn Cục (Global Plugin — Khuyên Dùng)
Để bộ 51 skills này **luôn tự động khả dụng trong MỌI dự án** trên máy tính mà không cần cài lại:
- **Windows (PowerShell):**
  ```powershell
  .\install.ps1 -Global
  ```
- **macOS / Linux (Bash):**
  ```bash
  chmod +x install.sh
  ./install.sh --global
  ```

### Cách 2: Cài đặt Riêng Cho Một Dự Án (Project-Scoped)
Nếu bạn chỉ muốn tích hợp bộ skills này vào một dự án cụ thể (`/path/to/my-project/.agents/skills/`):
- **Windows (PowerShell):**
  ```powershell
  .\install.ps1 -TargetProject "C:\path\to\my-project"
  ```
- **macOS / Linux (Bash):**
  ```bash
  ./install.sh --target /path/to/my-project
  ```
